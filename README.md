## ⚡ System Architecture

DIVERGE separates client presentation, high-throughput gateway routing, and persistent database storage through an asynchronous architecture:

```
                        ┌─────────────────────────────────────────┐
                        │      Client Browser (SvelteKit 2)       │
                        │  • Svelte 5 Reactive State Management    │
                        │  • SlicedWaves Ambient Canvas (40%)     │
                        │  • Universal Playback Singleton (Audio) │
                        │  • IndexedDB Blob Store + Service Worker │
                        └────────────────────┬────────────────────┘
                                             │
                       REST Requests / Auth  │  Audio Range / Master Streams
                                             ▼
                        ┌─────────────────────────────────────────┐
                        │         Go Backend (Fiber v2)           │
                        │  • Zero-Allocation FastHTTP Engine      │
                        │  • HMAC-SHA256 JWT Cookie Validation    │
                        │  • HTTP 206 Partial Content Range Stream│
                        │  • Sub-Second Multi-Catalog Search Hub  │
                        └────────────┬────────────────────────────┘
                                     │
                 GORM Relational Pool│
                                     ▼
                        ┌─────────────────────────────────────────┐
                        │         PostgreSQL 16 Database          │
                        │  • diverge_db (UTF-8, C Collation)      │
                        │  • 9 Normalized Relational Entities     │
                        │  • B-Tree Indexes on Foreign Keys & Tags│
                        └─────────────────────────────────────────┘
```

## 🌟 Comprehensive Feature Portfolio

### 1. High-Performance Audio Streaming
* **Full-Length Master Recordings:** All catalog tracks and search results stream authentic, complete studio master recordings (3 to 6+ minutes) with instant timeline seeking.
* **HTTP 206 Partial Content Range Streaming:** Go Fiber automatically slices audio streams into byte ranges, allowing instant scrub response without loading entire audio files into memory.
* **Persistent App Shell Playback:** Universal playback singleton ensures audio streams continuously without stuttering or re-buffering across client-side page transitions.
* **OS MediaSession API:** Direct operating system integration providing lockscreen track metadata, progress scrubbers, and hardware keyboard media key bindings.

### 2. Universal Instant Music Search
* **Immediate Query Resolution:** Sub-second response times (< 800ms) for global discographies, regional Indian hits (Bollywood, Tamil, Telugu, Punjabi), movie soundtracks, and international artists.
* **Top Header Centerpiece:** Sticky top search bar engineered with a continuous laser beam border glow, global `Ctrl + K` hotkey, and instant autocomplete preview hub.
* **Curated Genre Shortcuts:** Quick one-click discovery pills for trending musical styles (`#Bollywood Hits`, `#Tamil Hits`, `#Punjabi Beats`, `#Telugu Hits`, `#A.R. Rahman`, `#Synthwave`, `#Lo-Fi Chill`).
* **Direct Results Rendering:** Clean, unified search grid presenting track artwork, verified artists, exact durations, audio quality badges, and instant playback actions.

### 3. Liked Songs & Personal Collection
* **Interactive One-Click Favoriting:** Instant heart action on the bottom player bar and all song cards with Signal Coral (`#FF5C58`) fill state.
* **Session Persistence:** Dedicated favorites store synchronized to local storage (`diverge_liked_songs`), preserving personal collections across browser reloads.
* **Dedicated Navigation Destination:** Direct navigation link in the primary sidebar and a dedicated **Liked Songs** section inside `/library?tab=liked`.
* **One-Click Queue Playback:** Instant "Play Liked Songs" feature that compiles the listener's entire saved collection into the active queue.

### 4. Interactive Discovery Systems
* **Track DNA Visualizer:** Generates a deterministic SVG glyph per song based strictly on acoustic attributes (BPM, musical key, energy, and mood valence). Zero randomness; every song renders its identical visual signature across sessions.
* **Trace Journey:** Branching tree visualization representing personal listening paths over time, visually delineating continuous listening from exploratory genre shifts.
* **Diverge Sessions:** Real-time synchronized social listening rooms with 6-character room codes, shared queue management, and synchronized playback indicators.
* **Context Tags:** Multi-dimensional tagging system linking acoustic profiles to environmental contexts (`#midnight`, `#deep-focus`, `#chill-vibes`).

### 5. UI/UX Motion Engineering & Visual Craftsmanship
* **@react-bits/SlicedWaves Ambient Canvas:** Full-viewport reactive background running at calibrated **40% opacity**, rendering slatted sine ribbons in official brand colors (`#784BFF`, `#FF5C58`, `#FFAE33`) with cursor depth tracking.
* **Cinematic 3.5s Logo Onboarding:** Immersive introductory experience featuring concentric acoustic harmonic rings, the 3D DIVERGE emblem rising with spring physics, gradient wordmark tracking, and an audio frequency progress scrubber with instant skip capability.
* **Luxury Spotlight & Border-Beam Authentication:** Bespoke auth card with real-time radial cursor spotlight tracking, continuous Magic UI rotating conic border beam, fluid segmented tab slider, and a 4-bar soundwave equalizer loader (`||||`).
* **Enhanced 4-Feature Playback Player:**
  * **Queue Drawer:** Expandable slide-over panel displaying *Now Playing* with live animated equalizer bars and *Next Up* queue list with drag/jump actions.
  * **Connect to Device:** Target switcher (Browser 24-bit FLAC Engine, Studio Cast, DLNA, Studio Reference Headphones).
  * **Floating Miniplayer (PiP):** Compact docked widget with spinning vinyl artwork, real-time waveform bars, and quick transport controls.
  * **Fullscreen Studio Visualizer:** Immersive full-screen visualizer with grand typography, high-res artwork, and a 24-bar audio spectrum visualizer.
* **Bespoke Account Popover & Modals System:** Native-standard floating charcoal menu containing Account Overview, Profile, Recents, Upgrade to Premium (Studio Lossless), Support & Diagnostics, Private Session toggle, and Settings.

### 6. Client-Side Offline Playback
* **IndexedDB Binary Storage:** Client-side database caching audio blobs directly in the browser.
* **Service Worker App Shell:** Intercepts network calls to serve cached client assets and locally stored audio binaries without an active internet connection.

## 🗄️ Relational Database Schema (PostgreSQL 16)

The application utilizes 9 normalized relational entities managed through GORM auto-migrations:

| Table Name | Primary Key | Foreign Keys | Key Attributes & Constraints |
| :--- | :--- | :--- | :--- |
| `users` | `id` (bigserial) | None | `username` (unique), `email` (unique), `password_hash`, `avatar_url` |
| `artists` | `id` (bigserial) | None | `name` (index), `bio`, `image_url`, `jamendo_id` (unique) |
| `albums` | `id` (bigserial) | `artist_id -> artists.id` | `title` (index), `cover_url`, `release_year` |
| `songs` | `id` (bigserial) | `artist_id`, `album_id` | `title`, `duration`, `audio_url`, `bpm`, `energy`, `mood`, `genre`, `share_token` |
| `playlists` | `id` (bigserial) | `user_id -> users.id` | `name`, `description`, `cover_url`, `is_public`, `share_token` (unique) |
| `playlist_songs` | Composite PK | `playlist_id`, `song_id` | `position` (integer), `added_at` (timestamp) |
| `listening_histories` | `id` (bigserial) | `user_id`, `song_id` | `played_at` (index), `play_duration_seconds`, `context_tags` |
| `context_tags` | `id` (bigserial) | `user_id`, `song_id` | `tag_name` (index), `created_at` |
| `diverge_sessions` | `id` (bigserial) | `host_user_id`, `current_song_id` | `share_code` (unique), `name`, `is_playing`, `position` |
